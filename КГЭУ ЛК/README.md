# КГЭУ ЛК — личное Android-приложение

Приложение подключается к [kabinet.kgeu.ru](https://kabinet.kgeu.ru/webapp/) и показывает:

- расписание занятий;
- список дисциплин с оценками;
- детали ведомости (баллы по контрольным точкам).

Данные берутся из тех же API, что использует сайт личного кабинета.

## Сборка

1. Установите [Android Studio](https://developer.android.com/studio) (JDK 17 встроен).
2. Откройте папку проекта `КГЭУ ЛК`.
3. Дождитесь синхронизации Gradle.
4. Подключите телефон с включённой отладкой по USB **или** запустите эмулятор.
5. Run → `app`.

APK для установки вручную:

- Готовый файл: **`KGEU-LK-debug.apk`** в корне проекта (~19 МБ)
- Или после сборки: `app/build/outputs/apk/debug/app-debug.apk`

```bash
gradlew.bat assembleDebug
```

> На Windows проект нужно собирать из пути **без кириллицы** (например `C:\Temp\kgeu-lk`), иначе Android Gradle Plugin может упасть. Готовый APK уже лежит в папке проекта.

## Установка на телефон

1. Скопируй `KGEU-LK-debug.apk` на телефон (USB, Telegram, Google Drive — как удобно).
2. Открой файл на телефоне.
3. Разреши установку из неизвестных источников, если Android попросит.
4. Установи и запусти **КГЭУ ЛК**.

## Использование

1. Введите логин и пароль от личного кабинета КГЭУ (обычно email).
2. После входа доступны вкладки **Расписание** и **Баллы**.
3. В расписании переключайте дни стрелками.
4. В баллах нажмите на предмет, чтобы открыть детали ведомости.

Учётные данные хранятся локально в зашифрованном хранилище Android.

## Ограничения

- Если на аккаунте включена **двухфакторная аутентификация**, вход пока не поддерживается.
- При изменении API на стороне университета приложение может потребовать обновления.
- Приложение предназначено **только для личного использования**.

## Технологии

- Kotlin, Jetpack Compose, Material 3
- Retrofit + OkHttp
- EncryptedSharedPreferences
- Jsoup (разбор HTML ведомости)
